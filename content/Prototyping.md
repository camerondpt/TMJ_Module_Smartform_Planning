The [Prototyping Site](https://camerondpt.github.io/Form-Prototyper/) is where you can paste in example text (links below) to see what a working example might feel like in Epic. You can create prototypes from scratch on the website, or paste in existing text to trial it. Instructions on how to use the site can be found when it first loads.  If for some reason it's blank when clicking on the link, or if anything odd or weird is going on, try refreshing the site.  It **will not** save your work, you'll need to copy and paste what you work on into a word document or something similar.
